## 🛠️ Instrucciones de instalación

### 🖥️ Sistemas operativos

El código de la tarea fue desarrollado completamente en **Windows**.  
Si bien *en teoría* no debería haber problemas de compatibilidad con sistemas **Linux**, estos no fueron testeados, por lo tanto **no se garantiza su correcto funcionamiento** fuera de Windows.

### 🚀 Setup inicial

1. Clone este repositorio en un directorio de tu elección.
2. Se recomienda crear un entorno virtual de Python con la versión **3.11.9**, que fue la utilizada durante el desarrollo de la tarea.
3. Para instalar las dependencias necesarias, ejecute el siguiente comando en la carpeta raíz del repositorio:

```bash
pip install -r requirements.txt
```

4. Luego, simplemente ejecute el archivo `main.py`.
